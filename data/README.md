# Data

`recordings/` contains 31 WAV recordings named `Eko Recording Sound Export ...` (digital stethoscope exports). The file names mention auscultation sites or findings, but **no annotation file is provided**: there are no reference labels for B1/B2 positions or diagnoses.

**Provenance, consent and licence:** not documented in the original repository. The MIT licence of this repository covers the code only. If you reuse the recordings, verify their origin and terms first.
